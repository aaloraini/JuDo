JuDo

Simple To-Do Widget for macOS

Simple and user-friendly to-do widget for macOS. Easy to manage and track tasks from your desktop/Notification Center widget.

Download for macOS View Source

Features

Everything you need to manage your tasks efficiently

Desktop Widget

Access your tasks directly from the macOS Notification Center widget

Real-time Sync

Changes instantly reflected between the main app and widget

Drag & Drop

Easily organize tasks with drag-and-drop reordering

Smart Filtering

Hide completed tasks to focus on what matters

Quick Actions

Add, toggle, and manage tasks with minimal clicks

Secure & Private

All data stored locally on your Mac using secure App Groups

Technical Details

Built with modern macOS technologies

Technology Stack

SwiftUI: Modern declarative UI framework
WidgetKit: Native widget integration
App Groups: Secure data sharing
App Intents: Widget interactivity
Actor-based: Thread-safe data management

Key Features for Developers

Real-time Synchronization

Actor-based DataStore ensures thread-safe operations between app and widget

Widget Timeline Management

Smart timeline updates with 15-minute refresh cycles and intent-based updates

Comprehensive Logging

Built-in os.log integration for debugging and monitoring
